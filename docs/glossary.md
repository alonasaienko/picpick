# Глосарій

Єдине джерело назв у проєкті. Усі документи, діаграми, API і код використовують назви **тільки звідси**.

## 1. Предметні терміни

| Термін (UA) | Термін (EN, у коді) | Значення |
|---|---|---|
| Фотограф | Photographer | Користувач з акаунтом, який створює галереї й завантажує фото |
| Нікнейм | Nickname | Відображуване ім'я фотографа в акаунті; не є унікальним і не замінює email для входу |
| Клієнт | Client | Замовник фотографій; переглядає прев'ю і обирає кадри. Акаунта не має |
| Email | Email | Адреса електронної пошти фотографа: ідентифікатор для входу та адреса отримання email-сповіщень у цільовій системі |
| Email-сповіщення | Email notification | Автоматичний лист фотографу про подію в його галереї; описується для цільової системи, не реалізується в мінімальному прототипі |
| Галерея | Gallery | Набір фото з однієї зйомки, який фотограф показує одному клієнту |
| Оригінал | Photo (original) | Необроблений файл, завантажений фотографом. Клієнту ніколи не показується |
| Прев'ю | PhotoPreview | Зменшена копія оригіналу з вотермаркою, яку бачить клієнт |
| Вотермарка | Watermark | Напівпрозорий напис на прев'ю, що захищає кадр від використання без оплати |
| Посилання для клієнта | ShareLink | Приватне посилання з секретним токеном, за яким клієнт відкриває галерею |
| Токен | Token | Випадковий секретний рядок у посиланні, що замінює клієнту логін |
| Лайк | Like | Позначка клієнта «цей кадр мені подобається» |
| Вибір | Selection | Сукупність лайків клієнта в галереї |
| Відправка вибору | Submit selection | Дія клієнта, після якої вибір фіксується і більше не змінюється |
| Фіналізація галереї | Finalize | Дія фотографа, що закриває галерею для будь-яких змін |
| Термін дії | ExpiresAt | Дата, після якої галерея/посилання перестають бути доступними і підлягають видаленню |
| Обробка | Processing | Фонове створення прев'ю з вотермаркою для кожного оригіналу |

## 2. Актори і ролі

| Актор | EN | Як ідентифікується |
|---|---|---|
| Фотограф | Photographer | Email і пароль |
| Клієнт | Client | Токен у посиланні |
| Система | System | Внутрішні сервіси (Web App, Worker) |

## 3. Сутності

| Сутність | Що це | Зона |
|---|---|---|
| `Photographer` | Акаунт фотографа | A (Юля) |
| `Gallery` | Галерея | A (Юля) |
| `Photo` | Оригінал фото | B (Альона) |
| `PhotoPreview` | Прев'ю з вотермаркою | B (Альона) |
| `ShareLink` | Посилання для клієнта | C (Уля) |
| `Selection` | Вибір клієнта (лайки) | C (Уля) |

Поля і зв'язки сутностей опрацьовуються в п.7 (Data model).

## 4. Статуси

**Gallery.Status**

| Статус | Значення |
|---|---|
| `Draft` | Створена, фото ще не завантажені |
| `Processing` | Фото завантажені, триває обробка |
| `Ready` | Усі фото оброблені, можна ділитися |
| `Shared` | Створено посилання для клієнта |
| `Finalized` | Закрита фотографом, змін більше немає |
| `Expired` | Минув термін дії, очікує видалення |

**Photo.Status**

| Статус | Значення |
|---|---|
| `Uploaded` | Оригінал збережено, задача на обробку в черзі |
| `Processing` | Воркер накладає вотермарки |
| `Ready` | Прев'ю готове |
| `Failed` | Обробка не вдалася після всіх спроб |

**ShareLink (стан)**

| Стан | Значення |
|---|---|
| `Active` | Працює |
| `Expired` | Минув термін дії |
| `Revoked` | Відкликане фотографом |

**Selection.Status**

| Статус | Значення |
|---|---|
| `Open` | Клієнт ще обирає |
| `Submitted` | Клієнт відправив вибір, змінювати не можна |

## 5. Технічні компоненти

| Назва | Що це |
|---|---|
| Web App | ASP.NET Core застосунок: Razor Pages (UI), REST API, Identity |
| Worker | Python-сервіс, що створює прев'ю з вотермаркою |
| RabbitMQ | Брокер повідомлень між Web App і Worker |
| PostgreSQL | Основна база даних |
| MinIO | S3-сумісне сховище файлів (оригінали і прев'ю) |
| Черга задач | Черга, через яку Web App передає Worker'у фото на обробку |
| Черга подій | Черга, через яку Worker повідомляє Web App про результат |

## 6. Зони відповідальності

| Зона | Назва | Хто | Діапазон номерів |
|---|---|---|---|
| A | Акаунт і галереї | Юля | 1xx (FR-101, NFR-101, …) |
| B | Завантаження й обробка | Альона | 2xx |
| C | Доступ клієнта і вибір | Уля | 3xx |

## 7. Конвенції іменування

| Що | Стиль | Приклад |
|---|---|---|
| Сутності, класи | PascalCase, англійською, однина | `Gallery`, `PhotoPreview` |
| Статуси | PascalCase | `Ready`, `Submitted` |
| Поля в JSON | camelCase | `galleryId`, `expiresAt` |
| Шляхи API | kebab-case, множина | `/api/galleries/{id}/share-links` |
| Коди помилок (`errorCode`) | UPPER_SNAKE_CASE | `GALLERY_NOT_FOUND` |
| Таблиці БД | snake_case, множина | `galleries`, `share_links` |
| Python | snake_case | `process_photo()` |
| Файли документації | kebab-case | `zone-b-processing.md` |
